# Whiteboard الخاصة بي — الإصدار 2

## المميزات
- قلم، قلم عريض، قلم تمييز شفاف، ممحاة، خط، سهم، مستطيل، دائرة، نص، وإضافة صورة.
- اختيار اللون والسُمك وحجم النص.
- خلفية بيضاء أو شبكة أو نقاط أو سطور.
- تراجع وإعادة، مسح اللوحة، ولوحة جديدة.
- تكبير وتصغير وتحريك اللوحة.
- حفظ تلقائي محلي، وتصدير `.wboard` قابل لإعادة التعديل، وتصدير PNG.
- اختصارات لوحة المفاتيح.
- دعم PWA والتخزين المؤقت للعمل دون اتصال.

## تحديث المشروع على GitHub
ارفع محتويات هذا المجلد إلى المستودع الحالي واستبدل الملفات التي لها الأسماء نفسها. لا تحذف المستودع ولا تنشئ واحدًا جديدًا. تأكد أن `index.html` في جذر المستودع. اضغط Commit changes وانتظر GitHub Pages حتى يعيد النشر.

الملفات الأساسية: `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, ومجلد `icons`.

## اختصارات
P قلم، M قلم عريض، H تمييز، E ممحاة، L خط، A سهم، R مستطيل، C دائرة، T نص، Ctrl+Z تراجع، Ctrl+Y إعادة، Space مع السحب للتحريك.

## استخدام الصور
يمكن إدراج صور حتى 8 ميجابايت. إذا لم تُحفظ الصورة بسبب سعة التخزين في المتصفح، صدّر نسخة `.wboard` وقلّل حجم الصورة ثم أعد المحاولة.

## العمل دون إنترنت
يجب فتح الموقع عبر HTTPS مرة واحدة حتى يخزن المتصفح ملفات التطبيق مؤقتًا. قد يتطلب التحديث الجديد فتح الموقع مع الإنترنت مرة واحدة لتحديث التخزين المؤقت. اختبره قبل الاعتماد عليه، واحتفظ بنسخ احتياطية.
